# 使用说明

- 旅行当天直接打开网页会按设备日期进入行程，其他日期进入首页。行程和地图顶部都可以手动换日期。
- 每天先看建议出门时间、核心路线及注意事项。时间轴默认显示核心与交通，点「全部安排」展开顺路和可选点。景点附近的吃喝属于现场候选，门店和营业细节按来源核对。
- 景点和美食可以标为未完成、已完成或已跳过，收藏可独立设置。在摄影详情可收藏机位、标记拍过及保存私人备注。
- 地图为示意图，地点索引可按摄影、交通、美食等类别筛选。高德和 Apple 地图需要联网。跨海段核对官方轮渡，岛内主要步行。
- 「我的旅行信息」由本人填写。去地图导航时，地址或搜索词会交给所选的地图服务。两个设备不会实时同步。
- 「我的 → 伴手礼清单」可勾选已购买并保存金额。要计入实际支出时，在预算页另记一笔。人均实际支出以两人总支出除以二计算，账单另外保留共同支出标记。
- 导入前建议导出当前记录。清除数据需两次确认。导出的 JSON 包含本地私人信息，请妥善保管。
- 「我的 → 离线使用说明」显示缓存状态和 iPhone 安装步骤。出发前可以开飞行模式试一次。
