# 数据维护说明

| 文件 | 内容 |
| --- | --- |
| `data/itinerary.json` | 旅行日期、五个模块、时间段、核心路线、轮渡段和注意事项 |
| `data/attractions.json` | 稳定地点 ID、区域、类型、地图关键词、摄影及核实记录 |
| `data/food.json` | 店铺和特殊美食、地址、优先级、行程模块与地点关联 |
| `data/backup-spots.json` | 按区域组织的备用地点 ID |
| `data/map-positions.json` | WGS84 点位、来源及三条游客轮渡线的 OSM 路径 |
| `data/budget.json` | 预算口径、首版预估、支出类别、伴手礼 |

地点 ID 独立于行程日期。修改名称、时间或顺序时保留 ID，避免手机中的记录失去关联。重复到访的地点可在多个模块引用同一个 ID。低优先级的美食留在完整美食库里。预算未知项使用 `null`。如更换城市或日期，同时检查首页、纪念日、锁定日、返程车站等项目文本及本地备份版本。

核实记录包括 `status`、`source`、`checkedOn` 和 `note`。检查过来源仅代表当时可以找到参考。营业和时刻以旅行当天的官方或现场公告为准。添加或移除本地静态资源时同步编辑 `sw.js` 的文件清单，每次发布静态资源变更时递增缓存版本号。不要把私人信息、用户备份或真实账单加入 Git。

## 复核入口

- 轮渡官方资料列出东渡游客线与三丘田夜间往厦门轮渡码头。末班、检票和停航按实际日期确认。 [11 月航班调整公告](https://xmferry.com/xwzx/zxgg/32752.htm) · [游客乘船须知](https://m.xmferry.com/wx/gdzhn/yk/)
- 南普陀寺优先在微信搜索「南普陀寺预约服务平台」，按当日规则确认预约、开放和证件查验。 [预约规则报道](https://m.xm.bendibao.com/jieri/95214.shtm)
- 管风琴艺术中心与八卦楼是不同场馆，旅行日的演奏场次还需现场核实。 [场馆采购公告](https://8gtower.glyylq.cn/article.php?id=1308)
- 地图目录可查书店和茶饮门店的记录地址。当日营业情况需要复核。 [黄厝不在书店](https://www.amap.com/place/B0FFLO087B) · [茶满方庭厦大店](https://m.city8.com/xm/cater/8a25ua729gfhb279ac)

## 摄影素材

页面照片均为 Wikimedia Commons 的实景照片，经过裁剪、缩放并转为 WebP。署名和对应图片授权见 [实景照片与授权](../credits.html)。摄影模块的构图图是示意图，地点实景可另行搜索。

## 位置与底图

`data/map-positions.json` 按稳定地点 ID 保存源链接和经纬度。地理数据来自 [OpenStreetMap 贡献者](https://www.openstreetmap.org/copyright)，采用 [ODbL](https://opendatacommons.org/licenses/odbl/1-0/)。区域、街段或出入口参考会标明用途。找不到可靠 WGS84 点位时请留空，继续通过原数据的关键词链接查找。高德链接仅传关键词，不混用坐标。Leaflet 1.9.4 的许可证见 [LICENSE](../assets/vendor/leaflet/LICENSE)。

底图使用 OpenStreetMap 的标准瓦片，只在用户打开地图时请求可视范围，由浏览器按服务的 HTTP 缓存规则处理。Service Worker 不预缓存瓦片。项目无地图 Key，底图服务不可达时自动回退至站内示意图。[瓦片使用政策](https://operations.osmfoundation.org/policies/tiles/)

## 本地数据与后续共享

V2.0 保留 `xiamen-anniversary-2026-v1` 键和版本 1 的 JSON 结构。账本仍以原格式读写金额，计算用整数分。原始旅行数据与自定义记录继续按稳定 ID 关联。Service Worker 仅更新静态资源缓存。

当前状态校验、账本格式化与当地日期逻辑集中在 `assets/js/state.js`，界面统一经 `mutate` / `persist` 保存。未来接入双人同步时，可在保存边界增加用户主动启用的共享适配层，保留本地模式。实际接入前需分别配置认证、双人旅行成员关系和 Supabase 行级安全策略，再让用户确认同步范围与冲突处理方式。本版本未启用云同步。
