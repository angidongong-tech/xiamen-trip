# V3 维护者验收

- `supabase/tests/bootstrap-local.sql` 为一次性 PostgreSQL 测试环境创建最小 Auth 角色和用户表。随后执行 `supabase/setup.sql` 两次，再执行 `supabase/tests/permissions.sql`。权限测试会回滚示例数据。可使用开启 `wal_level=logical` 的 PostgreSQL 17。
- `tests/cloud-browser.mjs` 在本机 `/xiamen-trip/` 提供页面，把模拟的 Auth 和 Realtime 适配器连到隔离 PostgreSQL。设置 `XM3_PG_CONTAINER` 为容器名，选填 `PLAYWRIGHT_MODULE`、`CHROMIUM_PATH`，再由 Node 执行脚本。用 `XM3_LEGACY_ROOT` 指向 V2 源文件可复测 Service Worker 升级。脚本会创建示例房间，只应连接一次性测试数据库。
- 托管环境仍需在真机验证邮件确认、密码找回、会话过期恢复和实时订阅。用不同账号及浏览器会话走一次「手机配置指南」的验收，再导入实际账本。厦门当地网络可达性需用 Wi-Fi 和移动数据分别验证。
