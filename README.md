# 与海相约 · 厦门纪行

OUR FIRST ANNIVERSARY · XIAMEN

2026 年 11 月 28 日至 12 月 2 日的五天四晚双人旅行手账。11 月 30 日是一周年纪念日。适合在 iPhone 上快速查当天行程、机位、顺路吃喝和支出。

[打开旅行网页](https://angidongong-tech.github.io/xiamen-trip/)

## 手机上使用

- **行程**打开日期标签查看当天核心路线。点「全部安排」查看顺路和可选景点，「详情与拍照」可看构图、收藏机位和写备注。
- **地图**按日期和类别查询路线示意图及地点索引。点击地点可打开高德或 Apple 地图，或复制地址与搜索词。鼓浪屿跨海段乘游客轮渡。
- **我的 → 我的旅行信息**填写住宿名称、地址、抵达和厦门北站返程时间。如已购三丘田上岛船票，可在这里选择码头，鼓浪屿行程会自动调整。应用把信息显示在相应的住宿、抵达和返程卡片中。有返程发车时间时会计算建议的最晚到站时间。
- **我的 → 调整行程**交换中间三天的游玩模块，或恢复原始顺序。11 月 30 日保留纪念日属性。换日后核对预约、船票、开放和天气。
- **我的 → 预算管理**手动设总预算、记支出、修改或删除、按日期查账。预算可导出 JSON 或 CSV。¥4,580 是已知项目的两人旧版参考小计。
- **我的 → 导出与导入**可导出备份 JSON、从有效备份恢复。导入会整体替换当前记录，应用会先验证再确认。两部手机各自保存，使用备份手动共享。

## iPhone 和离线

用 Safari 打开网页，去「我的 → 离线使用说明」检查是否显示「核心行程已缓存」。点 Safari 的分享按钮，选择「添加到主屏幕」，再用主屏幕图标打开一次检查。缓存准备好后，行程、示意图、内置照片、美食和账本可以离线打开，地图导航和外链需要联网。Safari 清除站点数据时可能同时清除记录和缓存。Safari 标签页与主屏幕应用的存储可能分开，切换前可先备份。

## GitHub Pages

本应用是纯静态站点，发布源使用 **Deploy from a branch**，目录选 **/ (root)**。项目入口为 `index.html`，资源路径相对于站点根目录，`.nojekyll` 让 GitHub Pages 直接发布静态文件。

仓库 → **Settings → Pages → Build and deployment**。工作分支 `codex/xiamen-anniversary` 可直接用作发布源。若合并到 `main`，可将发布源切到 `main` 的根目录，再删除工作分支。手机上找不到 Settings 时，可在 Safari 的页面菜单选择「请求桌面网站」。

## 在本地打开

在项目目录执行 `python3 -m http.server 8000`，浏览器打开 `http://localhost:8000/`。用 HTTP 服务或线上 HTTPS 访问，以便加载 JSON 和使用 Service Worker。
